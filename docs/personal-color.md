# 사진 기반 퍼스널컬러 추천 v0.1

## 제품 목표와 흐름

졸업논문의 핵심 의도인 ‘나에게 어울리는 컬러 추천’을 웹에서 제공합니다.

사진 → 한 얼굴 검출 → 크기·얼굴 밝기 확인 → 양쪽 볼 색 추출 → CIELAB 특징 → 사용자 입력 대비와 함께 4계절 후보 평가 → 후보 2개·색상·설명 표시 → 사용자가 적용 → 코디 추천.

사진이 없거나 분석이 실패해도 직접 팔레트를 비교할 수 있습니다. 결과를 사진 입력 없이 만들어내거나 항상 같은 기본 계절을 추천하지 않습니다. 추천 적용은 사용자 선택으로 이루어지고 사진 기반 적용과 직접 선택을 구분합니다.

## 계산

얼굴 검출은 MediaPipe BlazeFace 모델입니다. 이 모델은 계절 유형을 분류하지 않습니다. 얼굴 박스의 양쪽 볼에 작은 영역을 설정하고 RGB 각 채널의 중앙값을 읽습니다. 매우 어둡거나 과노출된 픽셀을 제외하고, 한쪽당 유효 픽셀 60개 이상을 요구합니다. 이는 영역 안에 피부가 있다고 가정하는 샘플링이지 별도 학습 피부 분할이 아닙니다.

sRGB 역감마 → D65 XYZ → CIELAB 변환으로 L*(명도), a*·b*(색), C*(채도), 색상각을 계산합니다. 양쪽 볼의 ΔE76가 18을 넘으면 추천을 보류하고 9를 넘으면 촬영 재확인을 안내합니다. 이 기준은 검증된 조명 판정 기준이 아니라 초기 제품의 보수적인 운영 규칙입니다.

계절 점수는 warm(색상각 42–66도), bright(L* 35–80), vivid(C* 12–40), 사용자 선택 contrast(low=.15, medium=.5, high=.85)를 0–1로 정규화해 계산합니다.

```text
spring = .50 warm + .25 bright + .15 vivid + .10 (1-contrast)
autumn = .50 warm + .25 (1-bright) + .15 (1-vivid) + .10 (1-contrast)
summer = .50 (1-warm) + .15 bright + .15 (1-vivid) + .20 (1-contrast)
winter = .50 (1-warm) + .15 (1-bright) + .15 vivid + .20 contrast
```

상위 2개를 후보로 표시합니다. 점수 차이가 .10 미만이면 두 후보를 함께 비교하도록 안내합니다. 점수는 진단 확률이나 정확도가 아니며 사용자에게 백분율로 표시하지 않습니다. 임계값과 가중치는 전문가 라벨로 학습하거나 검증한 값이 아닙니다. 피부 명도만으로 계절을 결정하지 않지만 이 규칙이 피부톤별로 동일한 성능을 갖는다고 검증한 것도 아닙니다.

## 한계와 평가 계획

카메라 색상 재현·조명·화장·보정·얼굴 각도에 영향을 받습니다. 흰색 기준점 보정이나 색상표 캘리브레이션 없이 측정하는 사진 속 색은 실제 피부 반사색과 동일하지 않습니다. 계절 유형은 색상 조화를 평가하는 관행을 단순화한 제안으로, 생체색의 객관적 진단으로 취급하지 않습니다.

현재 테스트는 sRGB/Lab 수치, 이상 샘플 거부, 밝고 어두운 합성 색상의 연산 안정성, 대비 입력 반영, 실제 얼굴 검출→샘플→추천→코디 적용의 기능 검증입니다. 공개 NASA 사진 한 장의 기능 테스트는 계절 추천 정확도의 증거가 아닙니다.

다음 평가에는 동의받은 다양한 피부톤·기기·촬영 조건과 전문가 드레이핑 판정을 사용해 재촬영 일관성, 전문가 판정 일치율, 추천 팔레트 만족도, 피부톤별 차이를 확인해야 합니다. 검증 이후에만 모델 개선이나 성능 수치를 제시합니다.

## 개인정보·비용

모든 얼굴 검출·사진 샘플링·추천 계산은 브라우저에서 실행됩니다. 서버에 사진·RGB·Lab 특징을 보내지 않고 영구 저장하지 않습니다. 선택한 팔레트·출처는 기존 옷장·기록과 함께 localStorage에 저장됩니다. 사진 삭제 시 분석 데이터와 화면 결과를 제거하고 적용한 팔레트는 사용자 선택으로 남깁니다. 서버 추론 API나 Workers AI는 추가하지 않았습니다.
